### 🤖 Book RAG Q&A

An AI-powered **document question-answering system** designed around the Physical AI & Humanoid Robotics book.

The system uses retrieval to ground answers in the book's content instead of relying solely on an LLM's general knowledge.

**Architecture:**

```text
User
 ↓
Chat UI
 ↓
AI Agent
 ↓
Retrieval
 ↓
Qdrant Vector Database
 ↓
Book Content
 ↓
Grounded Response
```

**Stack:** `Python` `FastAPI` `OpenAI Agents SDK` `Qdrant` `PostgreSQL` `Neon` `RAG`
